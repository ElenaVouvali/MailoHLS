## Action feature boundary

The v4 tensorizer injects direct action-demand descriptors and a 108-wide action semantic summary at action nodes, in addition to common node attributes and graph edges. Demand features include masked rank/access/trip/arithmetic/dependence counts; unknown numerical values carry validity bits. `action_edge_summary` mean-pools supported semantic edge features for relevant array-access operations or loop-context operations. As a result, supported affine/access roles, recurrence and dependence status may already enter action features directly, but as an aggregate summary. The graph still carries individual operations, SSA values, access and dependence witnesses and typed edges for propagation. Exact witness identity, full affine map/source expression, which particular arithmetic operation is associated with which access, and the complete loop-carried producer/yield chain are not preserved as separate action-level tokens. Source IDs and witness records remain provenance/alignment rather than learned text features.
