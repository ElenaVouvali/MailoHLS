# Exact Davinci deployment source snapshot

The launcher, adapter, path configuration and environment/bundle preparation code
here are byte-preserving copies of the qualified 2026-11-13 deployment sources.
See [`docs/film_gmt_stage2_davinci_deployment.md`](../../../docs/film_gmt_stage2_davinci_deployment.md)
for identities, original execution paths and the audit/smoke receipts.

These snapshots retain the original absolute staging paths. Use an explicit new
deployment configuration when relocating them; do not modify protected model/data
receipts or substitute the current publication HEAD for the pinned execution
identity. No downloaded base model, V4/FiLM/GMT checkpoint, memory payload, Python
environment or nested Git/deployment mirror is committed in this directory.
