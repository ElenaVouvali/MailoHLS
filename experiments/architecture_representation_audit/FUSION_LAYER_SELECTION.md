# Fusion-layer selection: currently unresolved

## Decision

**No final layer or multi-layer set is selected.** The required cross-kernel Stage-1 compiler-property map, multi-family causal score interventions, and trained C evidence-use measurements are unavailable. Selecting layers now would violate the evidence criteria in this investigation.

The existing GEMV 32-layer study is a useful single-family prior: target context alters some actual margins; controlled post-attention activation patches alter candidate scores and occasionally rankings; reported responsive regions include middle and late layers. It proposes a future *pilot set* in that GEMV report, but those observations are not a general layer ranking and do not prove that compiler memory is useful at any one layer.

## Current evidence matrix

| Layer region | Hardware evidence | Structural gap | Causal sensitivity | Trained fusion evidence | Recommendation |
|---|---|---|---|---|---|
| Early | Existing GEMV context traces are less diagnostic of selected hardware signals here | No cross-kernel property probes | Patch contrast point exists but not structural-grounded | None | Keep one early contrast only if later pilot budget allows |
| Middle | Existing GEMV clock-state response concentrated around layers 9–15 | Unknown for the RC3 cohort | GEMV activation patch changed some candidate margins | None | Candidate pilot region, not selected |
| Late | GEMV device/budget state response and some score effects | Unknown for the RC3 cohort | GEMV patch effects include small sampled flips | None | Candidate pilot region, not selected |

No result is fitted on the one held-out GNN test family. No layer shortlist is selected from hidden-state movement alone.

## Bounded follow-up protocol

First complete exact-position, cross-kernel LLM property probes and causal hardware/structural controls. Then repair C route coverage and obtain a completed, authenticated trained C checkpoint under a separate authorization/resource window. Only after those data exist, select a small set of layers by the intersection of: (1) accessible hardware-conditioned queries, (2) a compiler-property gap in Stage-1 but recoverability in memory, (3) matched causal candidate-margin sensitivity, (4) enough downstream blocks to integrate evidence, and (5) stability across families. Do not use the final test family to choose layers.

Compare one layer at a time with identical frozen Stage-1, GNN, C memory, train/validation examples, loss, attention architecture/parameter count, initialization protocol, decoder, and update budget. Include no-memory, authentic memory, evidence-zero, within-program action/evidence shuffle, and parameter-matched control. Report evidence-dependent margin changes, gate/residual statistics, family-level validation directive behavior, and feasible measured QoR only where available. Joint-layer tests follow single-layer measurements and include leave-one-layer-out interventions. A fixed historical multi-layer recipe is a comparator only, not the default.
